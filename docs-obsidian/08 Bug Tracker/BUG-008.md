# BUG-008: Transaksi Bulan Lalu Tidak Tampil & Kurangnya Filter Periode Waktu

## Deskripsi
Transaksi dari bulan-bulan sebelumnya (misalnya bulan Juli) yang ada pada grafik Analitik tidak muncul di daftar riwayat **Transaksi**. Pengguna hanya bisa melihat transaksi terbatas pada 20 baris pertama. Selain itu, belum ada filter berbasis rentang waktu di halaman Transaksi.

## Alasan / Root Cause
1. `TransactionController.php` membatasi paginasi default ke `20` baris per halaman jika parameter `per_page` tidak dispesifikasikan.
2. `app/transactions/page.js` sebelumnya tidak menyertakan kontrol paginasi UI (tombol 1, 2, 3...) maupun filter rentang waktu (Bulan Ini, Bulan Lalu, Custom Tanggal).

## How to Solved
1. Memperbarui `TransactionController.php` untuk mendukung pembatasan paginasi yang stabil (default 15 baris per halaman, max 50 baris).
2. Memperbarui `app/transactions/page.js` dengan menambahkan:
   - Filter Periode Waktu: **Semua Waktu**, **Bulan Ini**, **Bulan Lalu**, dan **Custom Tanggal (Date Picker)**.
   - Paginasi Frontend: Navigasi Halaman (`1`, `2`, `3`...), tombol `◀ Sebelumnya` & `Selanjutnya ▶`, indikator jumlah data, dan selector baris per halaman (10, 15, 25, 50).
3. Melakukan build ulang Next.js (`npm run build`) dan restart PM2 (`keuangan-frontend`).
