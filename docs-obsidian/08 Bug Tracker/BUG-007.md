# BUG-007: Saldo & List Dompet Tidak Muncul di Halaman Dashboard

## Deskripsi
Meskipun pengguna telah memiliki beberapa dompet aktif (misalnya Cash, BCA, GoPay) dengan total saldo tertentu di halaman **Dompet**, halaman **Dashboard** justru menampilkan `Total Saldo Rp0`, `0 dompet aktif`, dan seksi dompet di bagian bawah menampilkan `"Belum ada dompet."`.

## Alasan / Root Cause
Penyebabnya terletak pada parsing respons API di `finance-app-web/app/dashboard/page.js`:
- Endpoint backend `/api/wallets` mengembalikan objek berstruktur:
  ```json
  {
    "wallets": [ ... ],
    "total_balance": 3810000,
    "formatted_total": "Rp3.810.000"
  }
  ```
- Di `app/dashboard/page.js`, kode melakukan pengecekan:
  ```javascript
  setWallets(Array.isArray(wData) ? wData : (wData.data || []));
  ```
- Karena `wData` berupa Objek (bukan Array) dan key data di API adalah `wallets` (bukan `data`), `wData.data` bernilai `undefined`, sehingga state `wallets` terisi array kosong `[]`.

## How to Solved
1. Memperbarui `finance-app-web/app/dashboard/page.js` pada blok penanganan `walletRes`:
   ```javascript
   setWallets(wData.wallets || wData.data || (Array.isArray(wData) ? wData : []));
   ```
2. Memperbarui juga penanganan `summaryRes` agar membaca `sData.summary || sData`.
3. Menjalankan ulang `npm run build` dan me-restart `keuangan-frontend` di PM2.
