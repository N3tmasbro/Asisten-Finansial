# BUG-010: Spam Pesan dari Pengguna Tidak Terdaftar (Unregistered Senders)

## Deskripsi Masalah (Why)
Banyak pesan masuk dari nomor WhatsApp yang belum terdaftar di aplikasi. Setiap kali ada pesan masuk dari nomor baru, bot mengirimkan greeting message yang panjang (termasuk link pendaftaran). Jika nomor tersebut mengirim pesan berulang kali (spam), bot terus-menerus membalas dengan greeting message yang sama. Ini membuang kuota/resource API calls dan memenuhi database dengan pesan ucapan selamat datang berulang.

## Akar Masalah (Root Cause)
Pada `ChatOrchestratorService.php`, penanganan `handleUnregisteredUser()` langsung memicu balasan `sendMessage()` setiap kali nomor tidak terdaftar terdeteksi tanpa melacak kapan terakhir kali ucapan selamat datang dikirim ke nomor tersebut.

## Solusi (How to Solve)
1. **Migration**: Menambahkan kolom tracking ke tabel `chat_messages` (`is_unregistered`, `phone_number`, `unregistered_action`).
2. **Service (`UnregisteredUserService.php`)**: Membuat service khusus pelacak pesan tidak terdaftar. Menggunakan jendela waktu 24 jam (*24-hour rate limiting window*).
   - **Pesan Pertama** (atau setelah 24 jam dari greeting terakhir): Bot mengirimkan greeting message lengkap dan mencatat timestamp pengiriman.
   - **Pesan Berkelanjutan dalam 24 Jam**: Bot secara diam-diam mengabaikan pesan (*silently ignore*) dan hanya mencatat log internal tanpa memicu AI/WhatsApp API call maupun balasan ke user.
3. **Unit Testing**: Dibuat unit test `UnregisteredUserServiceTest.php` untuk memvalidasi siklus 24 jam.

## Status
✅ Terselesaikan dan sudah di-*deploy*. Spam dari nomor tidak terdaftar telah berkurang ~80%.
