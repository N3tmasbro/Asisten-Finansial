# BUG-001: New User Cannot Create Manual Transactions

## Deskripsi
Pengguna baru yang baru mendaftar tidak bisa membuat transaksi manual melalui Web Dashboard. Saat mencoba menyimpan transaksi, sistem menampilkan error `422 Unprocessable Content` (Validasi Gagal) dengan keterangan bahwa `category_id` tidak valid atau wajib diisi.

## Alasan / Root Cause
Dalam form transaksi, pengguna wajib memilih kategori (`category_id`). Pada controller `TransactionController.php`, validasi mengharuskan kategori yang dipilih adalah milik user tersebut (aturan `exists:categories,id,user_id`). Namun, karena kategori default tidak di-seed (diisi) untuk pengguna baru secara otomatis pada saat registrasi, pengguna memiliki daftar kategori kosong `[]`.

## To-Do
- Menambahkan *seeder* untuk kategori bawaan (Income & Expense) yang bersifat global (tanpa `user_id` atau `is_default = true`).
- Menyesuaikan *scope* pada model `Category` agar pengguna dapat mengambil kategori global + kategori kustom mereka sendiri.
- Memodifikasi validasi di `TransactionController.php` untuk membolehkan penyimpanan transaksi menggunakan `category_id` global selain kategori kustom milik pengguna.

## How to Solved
1. Menjalankan `DefaultCategoriesSeeder` untuk membuat 12 kategori global (8 pengeluaran, 4 pemasukan) dengan `user_id = null`.
2. Memperbarui `TransactionController.php` pada *method* `store` dan `update`. Validasi kustom (`Rule::exists`) dimodifikasi dengan logika di mana `category_id` dianggap valid jika kategori tersebut dimiliki oleh `user_id` yang sedang login, ATAU `user_id` pada tabel kategori adalah `null` (kategori global).
3. Transaksi manual kini berhasil disimpan karena pengguna mendapatkan opsi kategori bawaan secara *default*.
