# BUG-003: No WhatsApp Verification Reminder on Dashboard

## Deskripsi
Pengguna yang baru saja menyelesaikan registrasi dan berhasil login, langsung diarahkan ke halaman `/dashboard`. Namun, Dashboard tidak menampilkan notifikasi apa pun mengenai perlunya verifikasi nomor WhatsApp. Pengguna tidak akan sadar bahwa bot WhatsApp belum mengenali mereka karena verifikasi OTP tersembunyi di dalam halaman `/settings`.

## Alasan / Root Cause
UI di komponen halaman Dashboard (`dashboard/page.js`) tidak memuat logika pemeriksaan status `phone_verified` dari objek profil pengguna (Auth). Akibatnya, alur penerimaan/onboarding (UX) terputus dan pengguna mungkin frustrasi karena bot WhatsApp mengabaikan pesan mereka.

## To-Do
- Mengakses *state* status verifikasi nomor WhatsApp pengguna.
- Merancang dan menampilkan komponen antarmuka (banner peringatan) di halaman Dashboard.
- Memastikan banner tersebut memiliki CTA (Call-to-Action) yang mengarahkan pengguna ke halaman pengaturan untuk verifikasi.

## How to Solved
1. Di dalam `finance-app-web/app/dashboard/page.js`, *hook* otentikasi (`useAuth()`) diimpor untuk mengambil data `user`.
2. Menambahkan *conditional rendering* di bagian teratas *layout* Dashboard: `if (!user.phone_verified)`.
3. Jika evaluasi bernilai salah (nomor belum terverifikasi), sistem me-render sebuah banner peringatan bergaya visual *highlight* warna kuning/amber, dengan pesan peringatan: *"Nomor WhatsApp kamu belum diverifikasi"*.
4. Menambahkan tombol / tautan (CTA) di dalam banner yang akan merutekan (redirect) pengguna secara cepat langsung menuju halaman `/settings` untuk mengirim kode OTP ke WhatsApp mereka.
