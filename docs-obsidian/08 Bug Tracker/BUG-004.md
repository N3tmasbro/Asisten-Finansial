# BUG-004: WhatsApp Bridge Bad MAC Session Error

## Deskripsi
Koneksi WhatsApp Bridge sering mengalami *error* di *background* yang merusak fungsi bot. Konsol Node.js mencatat *error* secara berulang: `"Failed to decrypt message with any known session... Session error:Error: Bad MAC"`. 
Meskipun terjadi kesalahan fatal secara internal (dekripsi enkripsi *end-to-end* WhatsApp gagal), status bot di Web Dashboard masih tertulis `"Terhubung ✅"`, sehingga pengguna mengira semuanya normal padahal bot sudah tidak merespons (lumpuh).

## Alasan / Root Cause
Library Baileys/libsignal yang digunakan untuk jembatan (bridge) WhatsApp mengalami kegagalan validasi *MAC* (Message Authentication Code) ketika kunci enkripsi sesinya tidak sinkron dengan *client* WhatsApp pusat (misal karena pergantian sesi atau perangkat). *Error* ini dilempar di level bawah library dan hanya dicetak menggunakan `console.error()`.
API `/status` bawaan bridge hanya mengecek variabel koneksi soket (`sock?.user`), di mana nilai tersebut tetap ada (karena secara teknis websocket masih *"connected"*) walaupun mesin enkripsi (E2EE) lumpuh.

## To-Do
- Mengintersepsi atau membaca *error* internal dari pustaka Baileys yang dicetak di konsol.
- Membuat *flag* state internal pada `index.js` WhatsApp Bridge untuk melacak jika ada kerusakan MAC.
- Mengirim status *"disconnected"* secara paksa dengan pesan spesifik ke Frontend via API `/status`.
- Menampilkan pesan kerusakan dan panduan perbaikan ("Tidak Terhubung") kepada pengguna di dasbor Pengaturan.

## How to Solved
1. Di dalam file `whatsapp-bridge/src/index.js`, saya memodifikasi *method override* `console.error` bawaan aplikasi.
2. Setiap pesan `console.error` yang dicegat diinspeksi. Jika *string* *log* memuat teks `"Bad MAC"` atau `"Failed to decrypt message"`, saya mengatur variabel global `hasBadMacError = true`.
3. Rute HTTP `GET /status` diperbarui untuk tidak hanya mengecek `sock?.user`, tetapi juga nilai `!hasBadMacError`. Jika rusak, API mengembalikan JSON: `status: 'disconnected'` dengan `error: 'Terdeteksi Bad MAC...'`.
4. Frontend `app/settings/page.js` sudah siap menerima nilai `error` dari API. UI otomatis berubah menjadi `"Tidak Terhubung ❌"` disertai teks penjelasan `"Terdeteksi Bad MAC (Sesi enkripsi WhatsApp rusak). Silakan hubungkan ulang."`
