# BUG-002: Next.js 16 Deprecated `middleware.js` Warning

## Deskripsi
Saat frontend Next.js dijalankan dengan perintah `npm run dev`, console (terminal) selalu menampilkan pesan peringatan (warning) di awal startup:
*"The 'middleware' file convention is deprecated. Please use 'proxy' instead."*

## Alasan / Root Cause
Proyek menggunakan Next.js versi 16+ (versi terbaru). Pada versi ini, sistem konvensi untuk middleware telah berubah. Penamaan file `middleware.js` pada *root* direktori telah *deprecated*. Fungsi *route interception* / proteksi halaman kini harus menggunakan konvensi penamaan file `proxy.js` atau `proxy.ts`, dan fungsi utamanya harus diekspor dengan nama `proxy(request)`.

## To-Do
- Mengganti (migrasi) nama file middleware ke standar baru.
- Memperbarui sintaks di dalam file dari `export function middleware` menjadi `export function proxy`.
- Menghapus file lama agar Next.js tidak mendeteksinya lagi.

## How to Solved
1. Membuat file baru `proxy.js` di *root* folder `finance-app-web/`.
2. Memindahkan semua logika pengalihan (redirect) otentikasi (mencek token di cookie dan mengamankan rute dashboard) dari `middleware.js` ke `proxy.js`.
3. Mengubah nama ekspor fungsi utamanya menjadi `export function proxy(request)`.
4. Objek konfigurasi (`config.matcher`) tetap dipertahankan seperti aslinya.
5. Menghapus file `middleware.js` yang lama. Startup server frontend sekarang bersih tanpa peringatan depresiasi.
