# BUG-012: Format Tabel ASCII Berantakan di Mobile & Routing Keyword Budget/Dompet

## Deskripsi Masalah (Why)
1. **Tampilan Hancur di Mobile**: Saat user mengetik "Cek Transaksi", balasan bot menggunakan format *ASCII Monospace Table*. Di layar HP yang sempit, teks spasi panjang ini terkena *word-wrapping* berulang kali sehingga tabel menjadi tidak terbaca.
2. **Kesalahan Intent Keyword Routing**: Saat pengguna mengetik "Sisa budget", "Sis budget", atau "Cek Dompet", bot secara keliru jatuh ke *fallback* daftar transaksi (`listRecentTransactions`) alih-alih menampilkan daftar budget atau saldo dompet.
3. **Pesan Tanpa Nominal Dibiarkan**: Ketika pengguna mengetik pesan super singkat tanpa nominal (seperti *"bensin"*), backend menyimpan transaksi secara diam-diam dengan jumlah `Rp0`.

## Akar Masalah (Root Cause)
1. Format tabel di `InspectHandlerService.php` menggunakan string spasi `sprintf("%-23s | %-13s ...")` yang tidak kompatibel dengan layar smartphone.
2. Array `BUDGET_KEYWORDS` dan `WALLET_KEYWORDS` di `InspectHandlerService.php` tidak mencakup variasi bahasa gaul/singkatan seperti `sisa budget`, `sis budget`, `sis anggaran`.
3. Parameter `needs_clarification` dari DTO hasil ekstraksi AI Gemini tidak diperiksa pada `ChatOrchestratorService::handleTransaction()`.

## Solusi (How to Solve)
1. **Redesain Template WhatsApp**: Mengubah seluruh balasan inspeksi (Transaksi, Dompet, Budget) dari tabel ASCII menjadi format *bullet-list* emoji bertingkat yang *mobile-responsive*.
2. **Perluasan Keyword & Regex**: Menambahkan `sisa budget`, `sis budget`, `sis anggaran` ke `BUDGET_KEYWORDS` dan menambahkan penanganan khusus regex pada `InspectHandlerService.php`.
3. **Pencegahan Transaksi Rp0**: Menambahkan pengecekan `$parsedTransaction->needsClarification`. Jika nominal tidak disebutkan, bot menolak menyimpan dan meminta pengguna menyebutkan harga terlebih dahulu (contoh: *"Aku nangkep bensin, tapi nominal tidak disebutkan. Sebutkan nominalnya ya"*).

## Status
✅ Terselesaikan dan sudah di-*deploy*. Tampilan di aplikasi WhatsApp HP menjadi sangat rapi dan responsif.
